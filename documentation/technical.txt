* 6. Target Data Details:

		- Output Name: EVST_SCM_demand_history.csv
		- Location: ADLS Path (to be configured)
		- Format: CSV
		- Description: Transformed ABC sales order delta data for global demand planning

* 7. Job Flow / Pipeline Stages:
	+ Stage 1: Ingest ECC sales order delta data into a bronze table
	+ Stage 2: Transform data to include key organizational attributes (create lookup table, derive sales office value, segregate sales orders, update organizational elements, etc.)
	+ Stage 3: Export transformed data to a CSV file

* 8. Data Transformations / Business Logic:
	+ Step 1: Create a lookup table based on the join condition of ship-to country and customer classification values
	+ Step 2: Derive sales office value using the lookup table

	+ Step 4: Update organizational elements, master data attributes, transactional data quantities, units of measure, and quantity conversions to the EA (Each) unit of measure
