* **TR-DC-001: Identify Duplicates in Customers and Products Tables**
	+ Related Functional Requirement(s): FR-DC-001
	+ Objective: Implement a PySpark job to identify duplicates in customers and products tables and update the bronze layer.
	+ Target Cluster Configuration:
		- Cluster Name: Bronze Layer Cluster
		- Databricks Runtime Version: 7.3.x-scala2.12
		- Node Type: Standard_DS3_v2
		- Driver Node: 1 x Standard_DS3_v2
		- Worker Nodes: 2-5 x Standard_DS3_v2
		- Autoscaling: Enabled
		- Auto Termination: 30 minutes
		- Libraries Installed: spark-dbutils, fuzzywuzzy
	+ Source Data Details:
		- Dataset Name: customers_table
		- Location (Path/Table): adls://bronze_layer/customers_table
		- Format: Delta Lake
		- Description: Customers data stored in bronze layer
		- Dataset Name: products_table
		- Location (Path/Table): adls://bronze_layer/products_table
		- Format: Delta Lake
		- Description: Products data stored in bronze layer
	+ Target Data Details:
		- Output Name: updated_customers_table
		- Location: adls://bronze_layer/customers_table
		- Format: Delta Lake
		- Description: Updated customers data with duplicates identified
		- Output Name: updated_products_table
		- Location: adls://bronze_layer/products_table
		- Format: Delta Lake
		- Description: Updated products data with duplicates identified
	+ Job Flow / Pipeline Stages:
		1. Read data from customers_table and products_table
		2. Apply duplicate detection logic using fuzzywuzzy
		3. Update bronze layer with identified duplicates
	+ Data Transformations / Business Logic:
		- Step: Filter data to find probable duplicates
		- Description: Apply fuzzy matching on customer names and product names
		- Transformation Logic: Use fuzzywuzzy library to calculate similarity score
		- Step: Confirm duplicates by additional checks
		- Description: Verify duplicates by checking address and item names
		- Transformation Logic: Use PySpark to apply additional checks
	+ Error Handling and Logging:
		- Log errors and exceptions to a dedicated log table
		- Implement retry mechanism for failed tasks
