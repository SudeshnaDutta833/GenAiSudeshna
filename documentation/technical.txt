### TR-DPS-001
* Related Functional Requirement(s): FR-DPS-001
* Objective: Implement a PySpark job to ingest APM 5-Year Historical Sales Order Data into Azure Databricks.

#### Target Cluster Configuration:
* Cluster Name: DPS-Historical-Data-Ingestion
* Databricks Runtime Version: 7.3 LTS
* Node Type: Standard_DS3_v2
* Driver Node: Standard_DS3_v2
* Worker Nodes: 2-5 (autoscaling)
* Autoscaling: Enabled
* Auto Termination: 30 minutes
* Libraries Installed: spark-xml, delta-lake

#### Source Data Details:
* APM 5-Year Demand History flat files: SFTP server location, CSV format, Historical sales order data for the last 5 years.
* APM Regional mapping file: SFTP server location, CSV format, Mapping data for regional, sales orgs, and plant.

#### Target Data Details:
* Bronze Layer: Azure Databricks, Parquet format, Raw historical sales order data.
* Silver Layer: Azure Databricks, Parquet format, Transformed historical sales order data.
* Gold Layer: Azure Databricks, Parquet format, Filtered and aggregated historical sales order data.

#### Job Flow / Pipeline Stages:
* Connect to SFTP server to access flat files.
* Load flat files into Bronze Layer.
* Create lookup table based on regional mapping file.
* Join historical data with regional mapping table.
* Apply transformations based on HISTSTREAM column.
* Populate Sales Organization, Region, Sales Office, and Plant fields.
* Store transformed data in Silver Layer.
* Filter and aggregate data for consumption and store in Gold Layer.

#### Data Transformations / Business Logic:
* Step 1: Load flat files into Bronze Layer.
	+ Transformation Logic: Use PySpark to read CSV files and write to Parquet format.
* Step 2: Create lookup table based on regional mapping file.
	+ Transformation Logic: Use PySpark to read CSV file and create a lookup table.
* Step 3: Join historical data with regional mapping table.
	+ Transformation Logic: Use PySpark to join historical data with lookup table on product and LOC.
* Step 4: Apply transformations based on HISTSTREAM column.
	+ Transformation Logic: Use PySpark to determine Demand quantity and Return quantity based on HISTSTREAM column.

#### Error Handling and Logging:
* Use try-except blocks to catch and log exceptions.
* Log errors to a designated log file.
* Implement retry mechanism for failed tasks.
