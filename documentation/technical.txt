Here is the Technical Requirement Document (TRD) based on the provided Functional Requirement Document (FRD):

* **Technical Requirement ID**: TR-SCM-001
* **In scope and out of scope part(s)**: 
  * In scope: FR-SCM-001, FR-SCM-002 (Ingestion of APM historical sales order data and regional mapping data into Azure Databricks, transformation and processing of ingested data to generate demand history data, and export of processed data to a CSV file)
  * Out of scope: Creation and execution of test scripts

* **Objective**: Implement a PySpark job to ingest, transform, and export SCM Demand History data using Azure Databricks.

* **Target Cluster Configuration**:
  * Cluster Name: SCM Demand History Cluster
  * Databricks Runtime Version: Latest LTS version
  * Node Type: Standard_DS3_v2
  * Driver Node: Standard_DS3_v2
  * Worker Nodes: 2-5 nodes (autoscaling)
  * Autoscaling: Enabled
  * Auto Termination: Enabled (30 minutes)
  * Libraries Installed: PySpark, Pandas, NumPy

* **Source Data Details**:
  * Dataset Name: Historical Sales Order Data
    * Location: abfss://user-managed@{storage_account}.dfs.core.windows.net/inbound/isc/apm_onetime_history/apm_sales_order
    * Format: CSV
    * Description: Historical sales order data from JDA-APM
  * Dataset Name: Regional Mapping Data
    * Location: abfss://user-managed@{storage_account}.dfs.core.windows.net/inbound/isc/apm_onetime_history/apm_sales_org_plant_xref
    * Format: CSV
    * Description: Regional mapping data from JDA-APM

* **Target Data Details**:
  * Output Name: SCM Demand History Data
    * Location: abfss://mft@{storage_account}.dfs.core.windows.net/outbound/supply-chain-management/scm-demand-fcst/5Y_APM_onetime_SCM_demand_history.csv
    * Format: CSV
    * Description: Processed demand history data for SCM

* **Job Flow / Pipeline Stages**:
  * Ingest historical sales order data and regional mapping data into Bronze tables
  * Transform ingested data by joining historical sales order data with regional mapping data
  * Apply mapping rules to generate required fields
  * Load transformed data into Silver tables
  * Create Gold view from Silver table
  * Export Gold view data to CSV file

* **Data Transformations / Business Logic**:
  * Step: Ingest data into Bronze tables
    * Description: Load historical sales order data and regional mapping data into Bronze tables
    * Transformation Logic: PySpark job to read CSV files and load data into Bronze tables
  * Step: Transform ingested data
    * Description: Join historical sales order data with regional mapping data and apply mapping rules
    * Transformation Logic: PySpark job to join data and apply mapping rules
  * Step: Load transformed data into Silver tables
    * Description: Load transformed data into Silver tables
    * Transformation Logic: PySpark job to load data into Silver tables

* **Error Handling and Logging**:
  * Error handling: Implement try-except blocks to catch and log exceptions
  * Logging: Use Databricks logging to log job execution and errors
  * Log location: ADLS path (abfss://user-managed@{storage_account}.dfs.core.windows.net/logs/scm-demand-history)
