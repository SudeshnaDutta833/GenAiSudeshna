Here is the Technical Requirement Document (TRD) based on the provided Functional Requirement Document (FRD):

* **Technical Requirement ID**: TR-SCM-001

* **In scope and out of scope part(s)**: 
  * In scope: Ingestion of JDA-APM demand history data into Azure Databricks, Transformation and processing of demand history data, Export of processed data to a CSV file (FR-SCM-001, FR-SCM-002)
  * Out of scope: Creation/execution of test scripts

* **Objective**: Implement a PySpark job to ingest, transform, and export JDA-APM demand history data to a CSV file.

* **Target Cluster Configuration**:
  * Cluster Name: SCM Demand History Cluster
  * Databricks Runtime Version: 10.4.x-scala2.12
  * Node Type: Standard_DS3_v2
  * Driver Node: 1 x Standard_DS3_v2
  * Worker Nodes: 2-5 x Standard_DS3_v2 (autoscaling)
  * Autoscaling: Enabled
  * Auto Termination: Enabled (after 30 minutes of inactivity)
  * Libraries Installed: PySpark, Pandas, NumPy

* **Source Data Details**:
  * JDA-APM Demand History File: abfss://user-managed@{storage_account}.dfs.core.windows.net/inbound/isc/apm_onetime_history/apm_sales_order, CSV, Demand history data
  * JDA-APM Regional, Sales Org & Plant Mapping File: abfss://user-managed@{storage_account}.dfs.core.windows.net/inbound/isc/apm_onetime_history/apm_sales_org_plant_xref, CSV, Regional, sales org, and plant mapping data

* **Target Data Details**:
  * SCM Demand History Data: abfss://mft@{storage_account}.dfs.core.windows.net/outbound/supply-chain-management/scm-demand-fcst/5Y_APM_onetime_SCM_demand_history.csv, CSV, Processed demand history data

* **Job Flow / Pipeline Stages**:
  * Ingestion of JDA-APM demand history data into Bronze layer
  * Ingestion of JDA-APM regional, sales org, and plant mapping data into Bronze layer
  * Transformation of data into Silver layer
  * Creation of Gold layer view
  * Export of Gold layer view data to a CSV file

* **Data Transformations / Business Logic**:
  * Step 1: Join Bronze layer tables based on product and LOC columns
  * Step 2: Apply transformations as per the mapping provided in the input file
  * Step 3: Create a Gold layer view on top of the Silver layer table

* **Error Handling and Logging**:
  * Error handling will be implemented using try-except blocks in PySpark
  * Logging will be done using Databricks logging mechanisms, with log files stored in a designated location in ADLS
