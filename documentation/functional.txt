Here is the Functional Requirement Document (FRD) based on the given Business Requirement Document (BRD):

**1.0 Purpose**

The purpose of this project is to design a data ingestion and processing system to support accurate global demand planning by including key organizational attributes such as Sales Organization, Region, Sales Office, Plant, Planning partner, Demand quantity, and Return quantity.

**2.0 Data Product Design**

**2.1 Data Sources**

The data sources for this project are two flat files: 
1. JDA-ABC 5 years Order Demand History file
2. JDA - ABC Regional, sales orgs & plant mapping data file

**2.3 Data Transformation:**

The data transformation involves the following steps:

1. Ingest the two source files into the bronze layer.
2. Create a silver view (s_xyz.sales_orders_demand_fcst_ABC_onetime_history) by joining the two bronze tables based on the product and LOC columns.
3. Apply the mapping rules to populate the required fields such as Sales Organization, Region, Sales Office, Plant, Planning partner, Demand quantity, and Return quantity.
4. Create a gold view (g_external.v_sales_orders_demand_fcst_ABC_onetime_history) from the silver view.
