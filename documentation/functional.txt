**1.0 Purpose**
To integrate sales order data from multiple sources into a unified data product, enabling better decision-making and data-driven insights.

**2.0 Scope**
2.1: In scope for this document is:
* Integration of sales order data from `b_onc.Sales` and `b_onc.sales_org` tables
* Transformation and loading of data into `s_onc.sales_ord_his` table
2.2: Out of scope for this document is:
* Data quality checks and validation
* Data visualization and reporting

**4.0 Roles and Responsibilities**

* Data Analysts: responsible for consuming the integrated data product
