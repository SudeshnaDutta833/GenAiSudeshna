### 7.2 Data Ingestion:

1. Ingest historical sales order data and regional mapping data from JDA-ABC system into Bronze layer.
2. Store data in Bronze tables: `b_um_xyz.ABC_onetime_history_sales_orders` and `b_um_xyz.ABC_onetime_history_sales_org_plant_xref`.

### 7.3 Data Transformation:

1. Create Silver table: `s_xyz.sales_orders_demand_fcst_ABC_onetime_history`.
2. Enrich dataset with regional Sales Organization and Plant mapping using join condition on product and LOC.
3. Populate key fields: Sales Organization, Region, Sales Office, Plant, Planning Partner, Demand Quantity, and Return Quantity.

**Flow Diagram:**

* Bronze Layer: Ingest historical sales order data and regional mapping data
* Silver Layer: Enrich dataset with regional Sales Organization and Plant mapping
* Gold Layer: Create gold view

**Schema TableName Description**

| Schema | TableName | Description |
| --- | --- | --- |
| b_um_xyz | ABC_onetime_history_sales_orders | Bronze table for historical sales order data |
| b_um_xyz | ABC_onetime_history_sales_org_plant_xref | Bronze table for regional mapping data |
| s_xyz | sales_orders_demand_fcst_ABC_onetime_history | Silver table for enriched dataset |
| g_external | v_sales_orders_demand_fcst_ABC_onetime_history | Gold view for demand planning data |

### 7.4 Data Export:

1. Create CSV extract from Gold view: `g_external.v_sales_orders_demand_fcst_ABC_onetime_history`.
2. Store CSV file in ADLS path: `abfss://mft@{storage_account}.dfs.core.windows.net/outbound/supply-chain-management/scm-demand-fcst/5Y_ABC_onetime_SCM_demand_history.csv`.
