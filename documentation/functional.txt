Here are the requirements in bullet points for section 7.3 Data Transformation:

* Read data from bronze tables.
* Apply mapping rules to transform data, including:
	+ APO Planning Version: populate as APO version = 001 if product from sales_org is null or blank, otherwise use LOC column from both sources.
	+ APM Model Number: map against APO Product in SCM if product from sales_org is null or blank, otherwise use LOC column from both sources.
	+ Product Planner Code: map against Product Planner code in SCM if product from sales_org is null or blank, otherwise use LOC column from both sources.
	+ Country: trim to 2 characters if product from sales_org is null or blank, otherwise use LOC column from both sources.
	+ Sales Office: use LOC + map to Region Code via X-Ref if product from sales_org is null or blank, otherwise use LOC column from both sources.
	+ Planning Partner: based on DMDGROUP field in b_onc.Sales file, with specific rules for SALES, SAMPLES, and CONSIGN.
	+ Distribution Channel: default to 10.
	+ Customer Group: default to 500.
	+ Ship-To Party: default to NONE.
	+ Sold-to Party: default to NONE.
	+ WW Business: default to None.
	+ Strategy Center: default to None.
	+ Product Line: default to None.
	+ Planning Set: default to None.
	+ Product Subset: default to None.
	+ Item Category: default to None.
	+ Sales Document Type: default to None.
	+ Snapshot ID: use system date/time.
	+ Cal Month: map from STARTDATE.
	+ Base Unit of Measure: default to EA.
	+ Source System: default to 'JDAAPM'.
	+ Demand Quantity - MTS: HISTSTREAM = Actual Sales Qty.
	+ Total Demand: same as Demand Quantity.
	+ Returns Qty - MTS: HISTSTREAM = Return Qty.
* Store transformed data in silver table "s_onc.sales_ord_his".
