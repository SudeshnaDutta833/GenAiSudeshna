Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD):

**FR-APM-001: Ingest Historical APM Sales Orders Data**

* **Title:** Ingest Historical APM Sales Orders Data
* **Description:** The system must ingest 5 years of historical APM sales orders data from Edwards JDA file into Azure Databricks.
* **Preconditions:**
	+ Edwards JDA file is available in CSV format.
	+ Sales Org, Region, and Plant Mapping file is available in CSV format.
	+ Azure Databricks is configured and available.
* **Main Flow / Functional Steps:**
	1. System ingests Edwards JDA file into Bronze layer as-is.
	2. System ingests Sales Org, Region, and Plant Mapping file into Bronze layer as-is.
	3. System applies transformations to the ingested data based on the mapping document provided in DPS.
	4. System stores the transformed data in the Silver layer under the s_isc schema.
	5. System creates an external view in the g_external schema.
	6. System generates a CSV file named 5Y_JDA_APM_SCM_demand_history.csv from the transformed data.
	7. System places the CSV file in the designated ADLS location for SCM consumption.

**FR-APM-002: Transform Historical APM Sales Orders Data**

* **Title:** Transform Historical APM Sales Orders Data
* **Description:** The system must apply transformations to the ingested historical APM sales orders data based on the mapping document.
* **Preconditions:**
	+ Ingested data is available in Bronze layer.
	+ Mapping document is available and up-to-date.
* **Main Flow / Functional Steps:**
	1. System retrieves the ingested data from Bronze layer.
	2. System applies transformations based on the mapping document.
	3. System stores the transformed data in the Silver layer.

**FR-APM-003: Export Transformed Data to SCM**

* **Title:** Export Transformed Data to SCM
* **Description:** The system must export the transformed data to SCM in CSV format.
* **Preconditions:**
	+ Transformed data is available in Silver layer.
	+ ADLS location is configured and available for SCM consumption.
* **Main Flow / Functional Steps:**
	1. System generates a CSV file from the transformed data.
	2. System places the CSV file in the designated ADLS location.
	3. System triggers MFT to pick up the file and deliver it to SCM.

**FR-APM-004: Optimize and Secure Data**

* **Title:** Optimize and Secure Data
* **Description:** The system must optimize and secure the ingested and transformed data.
* **Preconditions:**
	+ Data is ingested and transformed.
	+ Azure Databricks is configured and available.
* **Main Flow / Functional Steps:**
	1. System runs regular optimization scripts to maintain table performance.
	2. System restricts data access to authorized user groups.
	3. System archives data for 15 days on Azure Data Lake Storage (ADLS).
