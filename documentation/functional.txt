### FR-DPS-001
#### Title
Ingest APM 5-Year Historical Sales Order Data

#### Description
The system must ingest 5 years of historical APM sales order data from flat files into Azure Databricks for global demand planning.

#### Preconditions
- APM 5-Year Demand History flat files are available in the designated SFTP server location.
- APM Regional, sales orgs, and plant mapping data files are available.
- Necessary access rights to connect to BD Landing Zone.

#### Main Flow / Functional Steps
1. Connect to the SFTP server to access APM 5-Year Demand History flat files and mapping files.
2. Load the flat files into the Bronze Layer of Azure Databricks.
3. Create a lookup table based on the regional mapping file.
4. Join the historical data with the regional mapping table on product and LOC to enrich the dataset.
5. Apply transformations based on the HISTSTREAM column to determine Demand quantity and Return quantity.
6. Populate Sales Organization, Region, Sales Office, and Plant fields based on the regional mapping table.
7. Determine Planning partner based on the DMDGROUP field.
8. Store the transformed data in the Silver Layer.
9. Filter and aggregate data for consumption and store it in the Gold Layer.

### FR-DPS-002
#### Title
Ingest APM Sales Order Delta Data from ECC System

#### Description
The system must ingest APM sales order delta data from the ECC system into Azure Databricks for global demand planning.

#### Preconditions
- ECC sales order delta data is available.
- Regional mapping data file is available.
- Necessary access rights to develop, test, and execute jobs in Azure Databricks.

#### Main Flow / Functional Steps
1. Ingest ECC sales order delta data into the Bronze Layer of Azure Databricks.
2. Create or update a lookup table based on the regional mapping file.
3. Join the sales order delta data with the regional mapping table on ship to country and Customer classification to derive Sales Office.
4. Populate Planning partner based on Sales Doc Type.
5. Apply necessary transformations to align with global planning hierarchies.
6. Store the transformed data in the Silver Layer.
7. Filter and aggregate data for consumption and store it in the Gold Layer.

### FR-DPS-003
#### Title
Data Ingestion and Scheduling

#### Description
The system must ingest data via Attunity for ECC sales order delta data and schedule data ingestion as per daily frequency where CDC is not an option.

#### Preconditions
- Attunity is configured for CDC.
- Data sources are identified and accessible.

#### Main Flow / Functional Steps
1. Configure Attunity for CDC to ingest ECC sales order delta data.
2. Schedule data ingestion for sources where CDC is not available.
3. Monitor data ingestion processes for errors or failures.

### FR-DPS-004
#### Title
Security and Access Control

#### Description
The system must provide necessary access controls to various environments (Dev/QA/Production) for development, testing, and execution of jobs.

#### Preconditions
- User roles are defined.
- Access rights are granted based on user roles.

#### Main Flow / Functional Steps
1. Grant access to users to connect to BD Landing Zone.
2. Provide access to develop, test, and execute jobs in Dev/QA environments.
3. Grant access to view visualizations in the Production Environment.

### FR-DPS-005
#### Title
Data Processing and Storage

#### Description
The system must process data in Azure Databricks following the multi-layer folder structure (Bronze, Silver, Gold).

#### Preconditions
- Azure Databricks is set up with the required multi-layer folder structure.

#### Main Flow / Functional Steps
1. Ingest raw data into the Bronze Layer.
2. Clean and augment data in the Silver Layer.
3. Filter and aggregate data for consumption in the Gold Layer.
