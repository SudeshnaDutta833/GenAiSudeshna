**1.0 Purpose**
To design and develop an inbound interface for SCM demand history data from JDA-APM to Azure Databricks.

**2.0 Scope**
2.1: In scope for this document is:
* Ingestion of JDA-APM demand history data into Azure Databricks
* Transformation and processing of demand history data
* Export of processed data to a CSV file

2.2: Out of scope for this document is:
* Creation/execution of test scripts

**3.0 Definitions / Acronyms**
| Term / Abbreviation | Definition |
| --- | --- |
| JDA-APM | JDA Advanced Planning Module |
| SCM | Supply Chain Management |
| ADLS | Azure Data Lake Storage |

**4.0 Roles and Responsibilities**
* Data Engineers: responsible for designing and developing the data pipeline
* Data Analysts: responsible for validating and verifying the processed data

**5.0 References**
Implement a PySpark job to ingest, transform, and export JDA-APM demand history data to a CSV file.

**5.1 Data Product Identification**
* Data Product: SCM Demand History Data
* Data Source: JDA-APM

**5.2 Data Product Specification**
* Data Format: CSV
* Data Frequency: One-time load

**7.0 Data Product Design**

### 7.1 Data Sources

### 7.2 Data Ingestion:
1. Ingest JDA-APM demand history data into Bronze layer (b_um_isc.apm_onetime_history_sales_orders table)
2. Ingest JDA-APM regional, sales org, and plant mapping data into Bronze layer (b_um_isc.apm_onetime_history_sales_org_plant_xref table)

### 7.3 Data Transformation:
1. Create a Silver layer table (s_isc.sales_orders_demand_fcst_apm_onetime_history) by joining the Bronze layer tables based on the product and LOC columns.
2. Apply transformations as per the mapping provided in the input file.

Flow Diagram:
```
Bronze Layer -> Silver Layer -> Gold Layer
```

Execution Steps:
1. Join the Bronze layer tables based on the product and LOC columns.
2. Apply transformations as per the mapping provided in the input file.
3. Create a Gold layer view (g_external.v_sales_orders_demand_fcst_apm_onetime_history) on top of the Silver layer table.

Schema:
| TableName | Description |
| --- | --- |
| b_um_isc.apm_onetime_history_sales_orders | Bronze layer table for demand history data |
| b_um_isc.apm_onetime_history_sales_org_plant_xref | Bronze layer table for regional, sales org, and plant mapping data |
| s_isc.sales_orders_demand_fcst_apm_onetime_history | Silver layer table for transformed data |
| g_external.v_sales_orders_demand_fcst_apm_onetime_history | Gold layer view for final data |

### 7.4 Data Export:
1. Export the Gold layer view data to a CSV file.
2. Store the CSV file in the specified ADLS path (abfss://mft@{storage_account}.dfs.core.windows.net/outbound/supply-chain-management/scm-demand-fcst/5Y_APM_onetime_SCM_demand_history.csv)

### 7.5 Data Processing
Databricks provides a unified platform for scalable and efficient data processing, powered by Apache Spark as its core engine. Here, Databricks notebooks are orchestrated using Databricks Workflows.

### 7.6 Data Optimization
Regular optimization scripts are scheduled in Databricks to maintain table performance and ensure efficient query execution.

### 7.7 Data Security
Data access in Databricks is restricted to authorized user groups, such as Data Engineers and Data Analysts, based on their roles and responsibilities.

### 7.8 Data Archiving
Data is archived for 15 days on Azure Data Lake Storage (ADLS).
