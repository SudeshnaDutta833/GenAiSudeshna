**1.0 Purpose**
To develop a data pipeline to ingest, transform, and export APM onetime history data from ADLS to a gold view and then to a CSV file.

**2.0 Scope**

* Ingesting data from ADLS paths to bronze tables
* Transforming data from bronze tables to a silver table based on the provided mapping
* Creating a gold view from the silver table
* Exporting data from the gold view to a CSV file

2.2: Out of scope for this document is:

### 7.2 Data Ingestion:

1. Ingest data from ADLS paths to bronze tables using PySpark.
2. Add two columns: "SrcFileName" and "SnapshotDate" to the bronze tables.

### 7.3 Data Transformation:

1. Create a silver table "s_onc.sales_orders_demand_fcst_apm_onetime_history" based on the provided mapping.
2. Join the bronze tables "b_onc.apm_onetime_history_sales_orders" and "b_onc.apm_onetime_history_sales_org_plant_xref" on LOC and DMDUNIT/PRODUCT columns.
3. Apply the transformation logic as per the provided mapping.

Flow Diagram:

* Bronze tables → Silver table → Gold view → CSV file

Execution Steps:

1. Create DDL scripts for bronze tables, silver table, and gold view.
2. Ingest data from ADLS paths to bronze tables using PySpark.
3. Transform data from bronze tables to silver table using SQL.
4. Create a gold view from the silver table.
5. Export data from the gold view to a CSV file.

Table Details:

| Schema | TableName | Description |
| --- | --- | --- |
| b_onc | apm_onetime_history_sales_orders | Raw historical order demand data from JDA. |
| b_onc | apm_onetime_history_sales_org_plant_xref | Sales org and plant mapping data. |
| s_onc | sales_orders_demand_fcst_apm_onetime_history | Transformed Silver table based on business mapping logic. |
| g_external | v_sales_orders_demand_fcst_apm_onetime_history | Gold view |

### 7.4 Data Export

1. Export data from the gold view to a CSV file.
2. Upload the CSV file to the specified ADLS path.
