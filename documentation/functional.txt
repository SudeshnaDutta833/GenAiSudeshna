**1.0 Purpose**
To design and implement a data processing pipeline to ingest, transform, and export ABC historical sales order data for global demand planning.

**2.0 Scope**
2.1: In scope for this document is:
* Ingestion of ABC historical sales order data and regional mapping data from flat files
* Transformation of data using Databricks notebooks
* Export of transformed data to a CSV file for SCM demand forecasting
2.2: Out of scope for this document is:
* Creation/execution of test scripts

### 7.2 Data Ingestion:

1. Ingest historical sales order data and regional mapping data from flat files into Bronze layer tables.
2. Use Databricks notebooks to read data from ADLS paths.

### 7.3 Data Transformation:

1. Create a Silver layer table by joining historical sales order data with regional mapping data on product and LOC.
2. Apply transformation rules to populate key fields such as Sales Organization, Region, Sales Office, Plant, Planning Partner, Demand Quantity, and Return Quantity.
3. Create a Gold layer view by selecting required columns from the Silver layer table.

Flow Diagram:

* Bronze Layer (Raw data ingestion)
	+ Historical sales order data
	+ Regional mapping data
* Silver Layer (Data transformation)
	+ Join historical sales order data with regional mapping data
	+ Apply transformation rules
* Gold Layer (Filtered and aggregated data)
	+ Select required columns from Silver layer table

Schema TableName Description:

| Schema | TableName | Description |
| --- | --- | --- |
| b_um_xyz | ABC_onetime_history_sales_orders | Bronze layer table for historical sales order data |
| b_um_xyz | ABC_onetime_history_sales_org_plant_xref | Bronze layer table for regional mapping data |
| s_xyz | sales_orders_demand_fcst_ABC_onetime_history | Silver layer table for transformed data |
| g_external | v_sales_orders_demand_fcst_ABC_onetime_history | Gold layer view for filtered and aggregated data |

### 7.4 Data Export:

1. Export the Gold layer view to a CSV file.
2. Use Databricks notebooks to write data to ADLS path.

### 7.6 Data Storage:
Data is stored from source to target in the following locations:
* Bronze Layer: ADLS path - abfss://user-managed@{storage_account}.dfs.core.windows.net/inbound/xyz/ABC_onetime_history/
