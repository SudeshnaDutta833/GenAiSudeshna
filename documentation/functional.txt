**1.0 Purpose**
To design and implement a data processing pipeline to ingest, transform, and export ABC historical sales order data for demand planning purposes.

**2.0 Scope**
2.1: In scope for this document is:
* Ingestion of ABC historical sales order data and regional mapping data from flat files
* Transformation of ingested data into a consumable format
* Export of transformed data to a CSV file for downstream consumption
2.2: Out of scope for this document is:
* Creation/execution of any test script

### 7.2 Data Ingestion:

1. Ingest historical sales order data from flat file into Bronze layer (b_um_xyz.ABC_onetime_history_sales_orders)
2. Ingest regional mapping data from flat file into Bronze layer (b_um_xyz.ABC_onetime_history_sales_org_plant_xref)

### 7.3 Data Transformation:

1. Create Silver layer table (s_xyz.sales_orders_demand_fcst_ABC_onetime_history) by joining historical sales order data with regional mapping data on product and location
2. Apply transformations to populate key fields such as Sales Organization, Region, Sales Office, Plant, Planning Partner, Demand Quantity, and Return Quantity

**Flow Diagram:**

```
Bronze Layer (b_um_xyz.ABC_onetime_history_sales_orders)
                  |
                  |
                  v
Silver Layer (s_xyz.sales_orders_demand_fcst_ABC_onetime_history)
                  |
                  |
                  v
Gold Layer (g_external.v_sales_orders_demand_fcst_ABC_onetime_history)
```

**Schema TableName Description**

| Schema | TableName | Description |
| --- | --- | --- |
| b_um_xyz | ABC_onetime_history_sales_orders | Bronze layer table for historical sales order data |
| b_um_xyz | ABC_onetime_history_sales_org_plant_xref | Bronze layer table for regional mapping data |
| s_xyz | sales_orders_demand_fcst_ABC_onetime_history | Silver layer table for transformed data |
| g_external | v_sales_orders_demand_fcst_ABC_onetime_history | Gold layer view for consumable data |

### 7.4 Data Export:

1. Create CSV extract from Gold layer view (g_external.v_sales_orders_demand_fcst_ABC_onetime_history)
2. Export CSV file to abfss://mft@{storage_account}.dfs.core.windows.net/outbound/supply-chain-management/scm-demand-fcst/5Y_ABC_onetime_SCM_demand_history.csv
