### 1.0 Purpose
The purpose of this project is to design and implement a data ingestion and processing pipeline to support accurate global demand planning by incorporating ABC historical sales order data. The data will be sourced from flat files, processed through multiple layers (bronze, silver, and gold), and ultimately generate a CSV extract for downstream applications.

### 2.0 Data Product Design

#### 2.1 Data Sources
The data sources for this project are two flat files:
1. ABC Demand History file
2. ABC Regional, Sales Orgs & Plant mapping file

#### 2.3 Data Transformation:
1. **Bronze to Silver:**
   - Ingest raw data from the bronze layer into the silver layer.
   - Join the Demand History file with the Regional, Sales Orgs & Plant mapping file on `DMDUNIT = Product` and `LOC = LOC` to enrich the dataset.
   - Apply transformation rules to populate key fields such as Sales Organization, Region, Sales Office, Plant, and Planning Partner based on the joined data and specific business logic.

2. **Silver to Gold:**
   - Filter the data to include only historical and return data (HISTSTREAM = 'HIST' or 'RTNS').
   - Create a gold view that aggregates and filters the data for consumption.
