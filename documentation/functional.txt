Here is the detailed Functional Requirement Document (FRD) based on the provided Business Requirement Document (BRD):

**1.0 Purpose**

The purpose of this project is to design and implement a data ingestion and processing pipeline to support accurate global demand planning by including key organizational attributes such as Sales Organization, Region, Sales Office, Plant, Planning partner, Demand quantity, and Return quantity from ABC historical sales order data.

**2.0 Data Product Design**

### 2.1 Data Sources

The data sources for this project are two flat files:

*   JDA-ABC 5 years Order Demand History file
*   JDA-ABC Regional, sales orgs & plant mapping data file

The input file layouts are as follows:

### 2.2 Data Ingestion:

The data ingestion details are as follows:

| Source file | Source file location | Bronze table name |
| --- | --- | --- |
| JDA-ABC 5 years Order Demand History | abfss://user-managed@{storage_account}.dfs.core.windows.net/inbound/xyz/ABC_onetime_history/ABC_sales_order | b_um_xyz.ABC_onetime_history_sales_orders |
| JDA-ABC Regional, sales orgs & plant mapping data | abfss://user-managed@{storage_account}.dfs.core.windows.net/inbound/xyz/ABC_onetime_history/ABC_sales_org_plant_xref | b_um_xyz.ABC_onetime_history_sales_org_plant_xref |

### 2.3 Data Transformation:

The data transformation steps are as follows:

1.  Ingest the JDA-ABC 5 years Order Demand History file and JDA-ABC Regional, sales orgs & plant mapping data file into the bronze layer tables `b_um_xyz.ABC_onetime_history_sales_orders` and `b_um_xyz.ABC_onetime_history_sales_org_plant_xref`, respectively.
2.  Create a silver layer table `s_xyz.sales_orders_demand_fcst_ABC_onetime_history` by joining the bronze layer tables on the condition `Product = DMDUNIT` and `LOC = LOC`. Apply the necessary transformations to populate the required fields, such as Sales Organization, Region, Sales Office, Plant, Planning partner, Demand quantity, and Return quantity.
3.  Create a gold layer view `g_external.v_sales_orders_demand_fcst_ABC_onetime_history` on top of the silver layer table.

### 2.4 Data Export

The data export details are as follows:

| Source table | Extract name | Extract location |
| --- | --- | --- |
| g_external.v_sales_orders_demand_fcst_ABC_onetime_history | 5Y_ABC_onetime_SCM_demand_history.csv | abfss://mft@{storage_account}.dfs.core.windows.net/outbound/supply-chain-management/scm-demand-fcst/ |

The extract will be generated in CSV format and will contain the required fields, such as APO Planning Version, ABC Model Number, Country, Sales Office, Sales Organization, PLANT, Planning Partner, Demand Quantity - MTS, Returns Qty - MTS, and other relevant fields.
